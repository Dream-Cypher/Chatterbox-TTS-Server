# requirements-rocm-init.txt
#
# ROCm PyTorch stack - MUST be installed BEFORE requirements-rocm.txt
# Uses PyTorch's official ROCm 6.3 wheel index.
#
# torch >= 2.6.0 is a SECURITY FLOOR, not a preference: 2.5.1 and earlier are
# affected by CVE-2025-32434 (RCE via torch.load, even with weights_only=True),
# and the chatterbox package calls torch.load on .pt files downloaded from
# HuggingFace on every model load. This file previously pinned torch 2.5.1 on
# the rocm6.1 index, which has no wheel above 2.5.1 - hence the index move to
# rocm6.3, the lowest ROCm index carrying a torch above the floor.
#
# NOT TESTED ON AMD HARDWARE. This fork is developed on an RTX 4090, so the
# NVIDIA paths are verified and this one is not. It is changed because leaving a
# known-vulnerable pin in place was worse than an untested version bump. If it
# fails on ROCm, the fix is a version adjustment on this index, NOT a return to
# 2.5.1.
#
# The Dockerfile.rocm and start.py handle this automatically.
# For manual installation:
#   pip install -r requirements-rocm-init.txt
#   pip install -r requirements-rocm.txt
#   pip install --no-deps git+https://github.com/resemble-ai/chatterbox.git@5de7a54aa4e5e2baadb0182dde554908b48b85c2

-i https://download.pytorch.org/whl/rocm6.3
torch==2.9.1
torchaudio==2.9.1
torchvision==0.24.1
pytorch-triton-rocm
